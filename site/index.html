A little bot for every Claude Code session.

Agent Bots puts a tiny character above your Dock for each session you have running. It works while Claude works, waves when Claude needs you, and naps when the turn is done.

Read the room at a glance

Every state of a session has its own body language. No windows to check, no tabs to hunt through.

  • Working

    Claude is busy. Your bot runs, moonwalks, does the robot, or paints.

  • Needs you

    Claude is waiting on a permission. Your bot hops and waves a "!" until you answer.

  • Done

    The turn is finished. Your bot yawns, lies down, and sleeps.

  • Session over

    The session ended. Its bot dies, dramatically, and floats off as a ghost.

Subagents tag along

When Claude spins up subagents, they show up as smaller bots following their parent around. You can see how much help each session has called in.

Pick your crew

Six styles, all with the same moves. Pick one to swap the bots on the desktop up top. Switch any time from the menu bar.

Two minutes, no Terminal

  1. 1

    Download

    Get the .dmg and drag Agent Bots into Applications.

  2. 2

    Connect

    Open it and click Connect. It adds a small hook to your Claude Code settings and backs them up first.

  3. 3

    Start a session

    Run Claude Code in any terminal. A bot shows up within a second.

Nothing leaves your Mac. The hook writes one small file per session to your home folder, and the app reads it. Updates arrive on their own.

Needs Claude Code 2.1 or newer. Disconnect any time from the menu bar, and it takes the hook back out.
